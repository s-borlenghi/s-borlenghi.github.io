Privacy

In short: this website uses no cookies, doesn't track visitors and doesn't collect personal data.

What the website does

It is a personal presentation page. There are no forms, sign-ups, visitor analytics, ads or third-party content. Fonts and icons are hosted on the website itself, so the page doesn't contact other services.

Preferences stored in your browser

If you choose the language or the light or dark theme, your choice is stored only in your browser (localStorage), so it can be remembered next time. It is never sent anywhere, and you can delete it at any time from your browser settings. This is technical storage tied to a choice you make, so no consent banner is needed.

Hosting

The website is hosted by GitHub Pages, a service of GitHub, Inc. Like any web server, GitHub logs visitors' IP addresses for security purposes. I have no access to this data. Details are in the GitHub privacy statement.

External links

The LinkedIn and GitHub buttons lead to external websites with their own privacy policies.

Contact
